# 💗 For You — I Love You Python Animation

A romantic Python Pygame animation where an
"I Love You" heart is revealed after clicking
the "OPEN" button.

## ✨ Features

- 💗 Romantic "For You" intro screen
- ✨ Floating heart animation
- 🔘 Interactive OPEN button
- ❤️ "I Love You" heart formation
- 💕 Glowing text animation
- 📱 9:16 vertical layout
- 🐍 Built with Python + Pygame

## 🛠️ Requirements

- Python 3
- Pygame

## 📦 Installation

```bash
pip install pygame
